工具控隨手分享自己使用的軟體（Mac 為主）

喜歡用 Homebrew 管理自己安裝的軟體，每次換電腦只要匯出 brew list 就可以無痛轉移

安装 Homebrew
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

以下是我所安裝的軟體
```
# Essentials
brew install --cask arc # 潮潮的瀏覽器
brew install --cask cursor # 最近好難用，但我已經訂閱學生了就先將就一下
brew install --cask scroll-reverser # 用滑鼠習慣 natural scroll，跟 Trackpad 相反就會需要
brew install --cask mos # 讓你的滾輪更絲滑
brew install --cask google-drive # 可以無痛下載 Google Drive 上的大檔案
brew install --cask spotify # 聽音樂
brew install --cask zoom
brew install --cask audacity
brew install --cask discord
brew install --cask steam

# 開發用
brew install --cask docker-desktop # 
brew install --cask heptabase # 知識學習軟體，極推
brew install --cask iterm2

# 專注力工具
brew install --cask hazeover # 自動隱藏 non active 視窗，好用！
brew install --cask selfcontrol # 定時 block 網域，遠離社群

# 任務管理工具
brew install --cask ticktick # 極推！內建任務清單、習慣養成功能及蕃茄鐘，無痛開啟新人生
```

有些只有上架到 Mac AppStore 但沒有用 brew 包裝的軟體，可以用 brew 下載 mas（Mac AppStore 縮寫）

```
brew install mas
```

再透過 mas 安裝

```
mas install 539883307   # LINE
mas install 540348655   # Monosnap 特別喜歡他的箭頭（？
mas install 497799835   # Xcode 開發者必備
```
